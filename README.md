# WebGL Particle Wave Effects

A stunning WebGL particle wave effect inspired by modern creative websites. Features a dynamic terrain of particles with smooth color gradients.

## Features

- WebGL particle wave terrain
- 92K+ animated particles
- Smooth color gradient (blue to red)
- Mouse parallax effect
- Background dust particles
- Fully responsive

## Tech Stack

- React 19
- Three.js
- Custom GLSL shaders
- Vite
- Tailwind CSS 4
- TypeScript

## Getting Started

```bash
npm install
npm run dev
```

## Customization

Edit `src/components/ParticleWave.tsx` to customize:
- `NX`, `NZ` - Particle density
- `WIDTH` - Terrain width
- `POINT_SIZE` - Particle size
- Shader colors in `gradient()` function
